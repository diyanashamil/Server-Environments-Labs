# Introduction to Server Environments and Architectures

This repository documents my lab activities, commands, observations, and 
reflections for the **Server Environments and Architectures** unit at 
Murdoch University.

Each lab includes the steps taken, terminal outputs, screenshots, and key 
learnings, covering Linux/Windows server setup, virtualisation, cloud 
infrastructure (AWS/Azure), networking, DNS, security, and automation.

**Environment:** Ubuntu 24.04 LTS running on VMware Fusion (macOS host).
